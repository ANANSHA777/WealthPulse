# WealthPulse

WealthPulse is a full-stack enterprise resource and expense management platform designed for structured company workflows, AI-assisted insights, budget tracking, and role-based access control (Admin & Member dashboards).

## 🚀 Key Features

* **Role-Based Access Control (RBAC):** Dedicated workflows and UI permissions for Admin and Member accounts.
* **Company & Expense Management:** Real-time expense creation, categorization, and company budget tracking.
* **AI-Powered Insights:** Automated financial analysis and expense categorization powered by the Google Gemini API.
* **Secure Authentication:** JWT-based stateless authentication with password hashing using bcrypt.
* **Modern Interface:** High-performance single-page client built with React 18 and Vite.

---

## 🛠️ Tech Stack

* **Frontend:** React 18, Vite, CSS, JavaScript (ES6+)
* **Backend:** Node.js, Express.js
* **Database:** MongoDB with Mongoose ORM
* **Security & Auth:** JSON Web Tokens (JWT), bcrypt.js, Cors
* **AI Integration:** Google Gemini API (`@google/genai`)
* **Hosting:** Render (Backend API), Vercel (Frontend Client)
